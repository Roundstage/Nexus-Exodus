# Explosive Wave

Original expanding pink energy sphere inspired by the user reference, with a bright shell and translucent interior. Authored through Aseprite Lua.

Source: ExplosiveWave.aseprite; generator: CreateEnergySphere.lua; preview: ExplosiveWave.gif. Twenty 160 x 160 frames at 25 fps, 0.8 seconds, exported as a 5 x 4 sheet. Run Aseprite in batch with the Lua script, then node artifacts/ExplosiveWave/ExportExplosiveWaveDmi.cjs.

The game scales the 72px shell radius to the eight-tile attack radius and anchors it to the caster collision center. Combat values are unchanged.

The earlier Pixel Composer smoke sample remains in ../PixelComposerDiagnostics/ as a validated application test; it is no longer the in-game wave.
